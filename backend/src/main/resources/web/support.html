CadenceCam Support

Help with the CadenceCam web, iOS and Android apps

For support, email raz@raz.sg. Include the device, operating-system version and what you were trying to do, but never send a password or invitation access code.

Camera and counting

  • Allow camera access when CadenceCam asks for it.
  • Prop the phone securely where the moving part of the exercise crosses a substantial part of the picture.
  • Use even lighting and avoid a bright window behind the movement.
  • If the count is unstable, try another camera angle or use Camera controls to hold exposure and focus.

Counter and dashboard

Only one device can be the Counter for an account. A second device can display the Dashboard when both devices can reach each other on the same local network. Taking over the Counter signs the displaced Counter out of that role.

Login and account

The menu can log out only the current device, log out all devices, or permanently delete the account and its data. See the account-deletion instructions if you cannot use the in-app control.
